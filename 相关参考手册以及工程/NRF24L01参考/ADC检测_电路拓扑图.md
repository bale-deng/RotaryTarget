# STM32F103C8 ADC 检测电路拓扑图

## 一、引脚配置

| STM32 引脚 | ADC 通道 | GPIO 模式 | 说明       |
| ---------- | -------- | --------- | ---------- |
| PA0        | ADC1_IN0 | 模拟输入  | ADC 通道 0 |
| PA1        | ADC1_IN1 | 模拟输入  | ADC 通道 1 |
| PA2        | ADC1_IN2 | 模拟输入  | ADC 通道 2 |
| PA3        | ADC1_IN3 | 模拟输入  | ADC 通道 3 |

**基本参数**:

- 分辨率: 12 位 (0-4095)
- 电压范围: 0-3.3V
- ADC 时钟: 12MHz (72MHz/6)

## 二、关键注意事项

⚠️ **输入电压**: 必须在 0-3.3V 范围内,超出会损坏芯片  
✓ **滤波电路**: 强烈建议加 RC 滤波(1kΩ + 100nF)  
✓ **电源去耦**: VDDA 必须加 10μF + 100nF 电容  
✓ **分压保护**: 高于 3.3V 的信号必须分压后接入

## 三、软件使用

```c
// 1. 初始化
AD_Init();

// 2. 读取ADC值 (0-4095)
uint16_t value = AD_GetValue(ADC_Channel_0);

// 3. 转换为电压 (V)
float voltage = value * 3.3 / 4095.0;
```

---

**适用**: STM32F103C8 | **通道**: PA0-PA3 | **分辨率**: 12 位
