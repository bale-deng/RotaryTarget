# STM32F103C8 无线数据采集工程结构说明

## 一、工程概述

**项目名称**: NRF24L01 无线数据采集系统  
**主控芯片**: STM32F103C8T6  
**开发环境**: Keil MDK-ARM  
**主要功能**:

- 采集 4 路 ADC 模拟信号(PA0-PA3)
- 通过 NRF24L01 无线模块发送采集数据

## 三、核心模块说明

### 1. 主程序模块 (User/main.c)

**核心功能**:

```c
主循环流程:
1. 初始化NRF24L01无线模块
2. 初始化ADC模块
3. 循环执行:
   - 读取4路ADC值(AD0-AD3)
   - 数据打包(每个ADC值占2字节)
   - 通过NRF24L01发送
   - 延时100ms
```

**数据打包格式**:

```
TX_data[32] 发送缓冲区:
┌────┬────┬────┬────┬────┬────┬────┬────┬─────────┐
│ 0  │ 1  │ 2  │ 3  │ 4  │ 5  │ 6  │ 7  │  8-31   │
├────┼────┼────┼────┼────┼────┼────┼────┼─────────┤
│AD0H│AD0L│AD1H│AD1L│AD2H│AD2L│AD3H│AD3L│  预留   │
└────┴────┴────┴────┴────┴────┴────┴────┴─────────┘

H: 高8位  L: 低8位
```

### 2. NRF24L01 无线模块 (Hardware/NRF24L01.c)

**引脚连接**:

```
STM32引脚  →  NRF24L01
─────────────────────
PA4 (CSN)  →  CSN
PA5 (SCK)  →  SCK
PA6 (MISO) ←  MISO
PA7 (MOSI) →  MOSI
PB0 (IRQ)  ←  IRQ
PB10(CE)   →  CE
```

**主要函数**:

```c
void NRF24L01_Init(void)           // 初始化模块
uint8_t Send(uint8_t *Buf)         // 发送32字节数据
void Receive(uint8_t *Buf)         // 接收32字节数据
```

**通信参数**:

- 频率: 2.4GHz
- 速率: 1Mbps (可配置)
- 地址: 5 字节 (可自定义)
- 载荷: 32 字节
- 自动应答: 开启
- 重发次数: 10 次

### 3. ADC 模块 (Hardware/AD.c)

**引脚配置**:

```
STM32引脚  →  ADC通道
─────────────────────
PA0        →  ADC1_IN0
PA1        →  ADC1_IN1
PA2        →  ADC1_IN2
PA3        →  ADC1_IN3
```

**主要函数**:

```c
void AD_Init(void)                        // 初始化ADC
uint16_t AD_GetValue(uint8_t ADC_Channel) // 读取ADC值
```

**技术参数**:

- 分辨率: 12 位 (0-4095)
- 电压范围: 0-3.3V
- 采样时间: 239.5 周期
- 转换时间: 约 21μs
- ADC 时钟: 12MHz

## 五、开发注意事项

### 1. 硬件要求

**电源**:

- ⚠️ STM32 和 NRF24L01 必须使用 3.3V 供电
- ⚠️ ADC 输入电压范围: 0-3.3V (超出会损坏!)
- ✓ VDDA 需要加去耦电容: 10μF + 100nF

**信号连接**:

- ✓ NRF24L01 连接线长度 ≤ 20cm
- ✓ ADC 输入建议加 RC 滤波: 1kΩ + 100nF
- ✓ 共地连接,避免地环路

### 2. 软件配置

**时钟配置**:

```
系统时钟:  72MHz (HSE 8MHz × PLL×9)
PCLK2:     72MHz
ADC时钟:   12MHz (PCLK2/6)
```

**通信地址** (发送端和接收端必须一致):

```c
uint8_t T_ADDR[5] = {0x59, 0x51, 0x52, 0x21, 0x19};
uint8_t R_ADDR[5] = {0x59, 0x51, 0x52, 0x21, 0x19};
```

**数据解析** (接收端):

```c
// 还原ADC值
AD0 = (RX_data[0] << 8) | RX_data[1];
AD1 = (RX_data[2] << 8) | RX_data[3];
AD2 = (RX_data[4] << 8) | RX_data[5];
AD3 = (RX_data[6] << 8) | RX_data[7];

// 转换为电压
float voltage = (float)AD0 * 3.3 / 4095.0;
```

### 3. 常见问题及解决

**问题 1: NRF24L01 无法通信**

```
检查项:
□ SPI连线是否正确
□ 电源电压是否为3.3V
□ 发送/接收地址是否匹配
□ 通信频率设置是否一致
□ 天线是否完好
```

**问题 2: ADC 读数异常**

```
解决方案:
✓ 检查输入电压是否在0-3.3V范围
✓ 添加RC滤波电路(1kΩ + 100nF)
✓ 检查VDDA供电和去耦电容
✓ 多次采样求平均值
```
