# NRF24L01 与 STM32F103C8 电路拓扑连接图

## 一、引脚连接对照表

| STM32F103C8 | 引脚功能 | 方向  | NRF24L01 | 说明                     |
| ----------- | -------- | ----- | -------- | ------------------------ |
| PA4         | CSN      | OUT → | CSN      | SPI 片选信号(低电平有效) |
| PA5         | SCK      | OUT → | SCK      | SPI 时钟信号             |
| PA6         | MISO     | ← IN  | MISO     | SPI 主入从出(数据输入)   |
| PA7         | MOSI     | OUT → | MOSI     | SPI 主出从入(数据输出)   |
| PB0         | IRQ      | ← IN  | IRQ      | 中断信号(低电平有效)     |
| PB10        | CE       | OUT → | CE       | 芯片使能信号             |
| 3.3V        | VCC      | -     | VCC      | 电源正极(3.3V)           |
| GND         | GND      | -     | GND      | 电源地                   |

## 三、信号说明

### 1. SPI 通信信号组 (软件模拟 SPI)

#### CSN - 片选信号 (PA4 → NRF24L01)

- **功能**: SPI 片选信号,低电平有效
- **模式**: 推挽输出 (50MHz)
- **作用**: CSN=0 时选中 NRF24L01 进行通信,CSN=1 时取消选中

#### SCK - 时钟信号 (PA5 → NRF24L01)

- **功能**: SPI 时钟线
- **模式**: 推挽输出 (50MHz)
- **作用**: 提供数据传输的同步时钟

#### MISO - 数据输入 (PA6 ← NRF24L01)

- **功能**: 主入从出,STM32 接收数据
- **模式**: 上拉输入
- **作用**: 接收 NRF24L01 发送的数据

#### MOSI - 数据输出 (PA7 → NRF24L01)

- **功能**: 主出从入,STM32 发送数据
- **模式**: 推挽输出 (50MHz)
- **作用**: 向 NRF24L01 发送数据

### 2. 控制信号组

#### CE - 芯片使能 (PB10 → NRF24L01)

- **功能**: NRF24L01 工作模式控制
- **模式**: 推挽输出 (50MHz)
- **作用**:
  - CE=0: 待机模式
  - CE=1: 发送/接收模式激活

#### IRQ - 中断信号 (PB0 ← NRF24L01)

- **功能**: 中断请求信号,低电平有效
- **模式**: 上拉输入
- **作用**:
  - 发送完成时产生中断
  - 接收到数据时产生中断
  - 达到最大重发次数时产生中断

### 3. 电源信号

#### VCC

- **电压**: 3.3V (STM32 和 NRF24L01 共用 3.3V 电源)
- **注意**: NRF24L01 工作电压范围 1.9V-3.6V

#### GND

- **功能**: 电源地,共地连接

## 五、典型通信流程

### 写寄存器流程:

```
1. CSN = 0          (选中NRF24L01)
2. 发送指令字节     (W_REGISTER + 寄存器地址)
3. 发送数据字节     (要写入的值)
4. CSN = 1          (取消选中)
```

### 读寄存器流程:

```
1. CSN = 0          (选中NRF24L01)
2. 发送指令字节     (R_REGISTER + 寄存器地址)
3. 发送NOP接收数据  (读取返回值)
4. CSN = 1          (取消选中)
```

### 发送数据流程:

```
1. 写入TX载荷        (W_TX_PAYLOAD)
2. CE = 0           (准备切换模式)
3. 配置为发送模式    (CONFIG寄存器)
4. CE = 1           (激活发送)
5. 等待IRQ中断      (IRQ变为低电平)
6. 读取STATUS       (检查发送结果)
7. 清除中断标志     (写STATUS寄存器)
```
